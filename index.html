세 가지 테마
Theme 1
Enablement
직원 AI 작업 환경 제공
직원이 어떤 AI 도구를 쓰더라도, 결과물이 조직 자산으로 귀속되고 다른 직원의 작업에 맥락으로 활용되는 기반 구축.

채널 통일이 아닌, 데이터의 입구와 출구를 레포로 고정하는 방식.
핵심 과제
공통 AI 작업 레포 구축
데이터 분류 체계 (고객정보·인사 제외 기준)
도구별 어댑터 (CLAUDE.md, 시스템 프롬프트 등)
결과물 귀속 정책 + 자동화
Theme 2
Foundation
AI Friendly System 구축
내부 시스템을 AI가 이해하고, 접근하고, 활용할 수 있는 형태로 전환.

망분리가 출발점. 뚫어도 문제가 남는다 — 시스템 자체가 AI Friendly해야 한다.
핵심 과제
공통 레포 + 망분리 연결 레이어
API 게이트웨이 (IT본부 협력)
TR spec 정비 + 내부 API 카탈로그
Semantic API 레이어 (비즈니스 로직 단위)
LLM 연동 내부 툴킷
Theme 3
Value Creation
AI를 사업 가치로
AI를 내부 업무에서 외부 고객 경험·사업 경쟁력으로 무게중심 이동.

주축은 MTS(B2C). OpenAPI는 생태계를 외부 개발자·퀀트로 확장하는 인프라.
핵심 과제
내부 지식 체계 구축 (도움말·상품정보 AI 지식화)
개인정보 마스킹·익명화 체계
AI 검색 고도화 (자연어 통합 검색)
개인화 진입 (투자 성향 기반 추천)
OpenAPI 편의성 심화 + 생태계 포지셔닝
테마 간 연결 구조

논의 포인트

이 문서는 방향이지 결론이 아닙니다
이 문서는 방향의 초안입니다. 동의하지 않는 부분, 현장에서 다르게 보이는 부분, 누락된 맥락이 있다면 적극적으로 제시해 주시기 바랍니다.
현장의 감각과 이의제기가 이 계획을 완성합니다.
공통 질문 — AI/DATA혁신부
Q 01 · 이의제기
이 방향에서 동의하기 어렵거나 현장 현실과 맞지 않는다고 판단되는 부분이 있다면?
어떤 부분인지, 왜 그렇게 판단하는지 근거와 함께 제시해 주시기 바랍니다.
Q 02 · 현장 감각
현장에서 인지하고 있는 리스크나 맥락 중 이 계획에 반영되지 않은 것이 있다면?
각 테마에서 실제로 가장 크게 부딪힐 것으로 예상되는 지점을 구체적으로 제시해 주세요.
Q 03 · 실현 가능성
2027년 내 실현이 어렵다고 판단되는 과제가 있다면?
왜 어려운지 이유와 함께, 해당 과제 실행에 필요한 전제 조건도 제시해 주세요.
